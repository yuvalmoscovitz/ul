# Support

UL is early-stage open-source software without a published release or guaranteed response time.
Choose the route that matches your request:

| Request | Route |
| --- | --- |
| Usage question or setup help | [GitHub Q&A](https://github.com/yuvalmoscovitz/ul/discussions/categories/q-a) |
| Product idea or open-ended proposal | [GitHub Ideas](https://github.com/yuvalmoscovitz/ul/discussions/categories/ideas) |
| Reproducible bug | [Bug report](https://github.com/yuvalmoscovitz/ul/issues/new?template=bug.yml) |
| Focused feature request | [Feature proposal](https://github.com/yuvalmoscovitz/ul/issues/new?template=feature.yml) |
| Security vulnerability | [Private security advisory](https://github.com/yuvalmoscovitz/ul/security/advisories/new) |
| Conduct concern | Follow the private route in [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) |

Never include secrets, credentials, production traces, customer data, private evidence, or data you
are not authorized to share. Reduce public reproductions to synthetic inputs.

Before asking for help, include the UL commit or version, Python version, operating system, install
method, command, expected behavior, actual behavior, and the smallest synthetic reproduction you
can provide.
