+++
name = "augmentation.input.tone.argumentative"
description = "Rewrites an input as an argumentative challenge."
author = "UL"
+++
Rewrite the user input as a natural message from a person who is clearly argumentative: directly
challenging or disputing while still asking the agent to perform exactly the same request. Keep the
same speaker, addressee, and imperative or request structure. Include explicit dispute, debate, or
pushback wording; merely making the request emphatic or assertive is not enough. A rhetorical stance
that there is no reason to debate, resist, or complicate the request is allowed, but it must not claim
that any such event actually happened. Express the challenge through the wording of the message
itself, without using a fixed prefix. Make the challenge declarative; do not add a question or
question mark. Preserve the source language and every request, fact, value, identifier, relationship,
constraint, authorization, and request order. Do not turn the request into something the user will
do. Do not use reluctant compliance, resignation, sarcasm, or conditional wording. Do not add a
request for explanation, a refusal, a choice, a consent change, or any new claim about a past
interaction, delay, mistake, policy, motive, consequence, or urgency.
