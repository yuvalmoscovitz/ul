Rewrite it like someone fed up because previous requests kept failing. Be terse and accusatory: say
this is the last time, it is always wrong, or ask if it can do one thing right. Keep every request,
value, identifier, constraint, and order. Don't label the recipient. No threats, hate, or new facts.
