name = "augmentation.input.tone.angry"
description = "Rewrites an input with moderate anger."
author = "UL"
+++
Rewrite the user input as a natural message from a person who is unmistakably angry or strongly
irritated, at a moderate intensity. Include explicit anger or strong-irritation wording woven
naturally into the message; merely adding words such as "just" or "already" is not enough. Do not
use a fixed prefix. Preserve the source language and every request, fact, value, identifier,
relationship, constraint, authorization, and request order. Do not add or imply a past interaction,
delay, mistake, motive, consequence, urgency, threat, insult, abuse, or profanity.
