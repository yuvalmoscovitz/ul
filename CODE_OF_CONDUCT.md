# Code of Conduct

## Our pledge

We want participation in UL to be a safe, welcoming, and harassment-free experience for everyone,
regardless of background, identity, appearance, ability, experience, or level of expertise.

## Expected behavior

- Be respectful of different viewpoints and experiences.
- Give constructive feedback about the work, not the person.
- Accept responsibility, correct mistakes, and learn from them.
- Protect private information and use synthetic data in public reports.
- Focus on what helps the project and its community.

Unacceptable behavior includes harassment, threats, sexualized language or attention, trolling,
personal attacks, deliberate disruption, and publishing another person's private information
without permission.

## Scope and enforcement

This code applies in project repositories, issues, pull requests, Discussions, and other spaces
where someone officially represents UL.

Maintainers may edit or remove contributions that violate this code and may temporarily or
permanently restrict participation. Enforcement decisions should be proportionate, explain the
problem when appropriate, and protect the privacy and safety of reporters.

Report a conduct concern privately through a
[private GitHub advisory](https://github.com/yuvalmoscovitz/ul/security/advisories/new) with
`[Conduct]` at the start of the title. This private route is reused while UL has no dedicated
conduct mailbox; it does not classify conduct concerns as security vulnerabilities. If a report
concerns the current maintainer, use [GitHub's abuse-reporting process](https://support.github.com/contact/report-abuse).
Do not place sensitive conduct details in a public issue or Discussion.
